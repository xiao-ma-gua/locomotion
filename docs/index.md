# [人的肌肉骨骼运动](https://github.com/OpenHUTB/locomotion)

欢迎使用人的肌肉骨骼运动文档，该页面包含所有内容的索引。
> 所谓肌肉骨骼运动就是在 OpenSim、Mujoco、Chrono 这 3 个软件里通过复现人骨骼和肌肉的配合，来模拟人的运动，这样方便套用到人身上。
>
> 所以来这里就是学习如何使用 [Opensim](https://opensimconfluence.atlassian.net/wiki/spaces/OpenSim/overview) 、Chrono、Mujoco，以及肌肉骨骼运动方面的知识的，最终的目标是和 [hutb 模拟器](https://github.com/OpenHUTB/hutb) 进行协同模拟。
